## NEWLY DISCOVERED BLOCKER (Task 1 Investigation)

### theEventHasSkills (browse_steps.go) — FULLY BLOCKED

**Problem:** This is a Given step that adds skills to an existing event. It currently:
1. Creates skills via skillRepo.Create()
2. Gets events via env.GetEvents()
3. Updates event.Skills via eventRepo.Update()

**Why it cannot be migrated:** The event edit form (EditModal) uses CaptureEventFormData which does NOT include a Skills field. The UI simply doesn't support editing skills on events.

**Evidence:** 
- File: internal/cli/forms/capture_event_form.go:12-20
- Fields: Text, Date, Company, Project, Tags, Categories (NO Skills)
- Edit modal: internal/cli/screens/timeline/modals/edit_modal.go:53-61

**Options:**
1. Add Skills field to edit form (requires view update + form change)
2. Create skills at event creation time (like iHaveAnEventThatUsesSkill)
3. Keep direct DB call for this Given step (violates task requirements)

**Recommendation:** Add Skills field to event edit form. This enables both:
- Proper UI-based skill assignment in Given steps
- User ability to edit event skills (currently missing feature!)

**Status:** BLOCKED pending view update
