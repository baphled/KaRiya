# Feature: User Experience Principles

## Purpose
Define a user-centric approach to capturing and managing career events.

## Core UX Principles

### 1. Event-Centric Input
- Capture **what happened**, not CV bullets
- Prioritize natural, free-form text input

### 2. Progressive Enrichment
Phases of information capture:
- Phase 1: Raw capture
- Phase 2: Metadata clarification
- Phase 3: System-inferred competencies and role fit

### 3. Input Flexibility
Two primary input modes:
- Timeline journaling (default)
- CV backfill (import existing CVs)

### 4. Metadata Handling
- No audience/role required at input time
- Optional metadata: date, company, project
- Easy metadata editing

### 5. Editing Capabilities
- Split events
- Merge events
- Reclassify events
- **Never rewrite original text**

### 6. CV Generation
- Read-only generation
- Explainable process
- Reversible changes
- Transparent source tracing

### 7. User Feedback
- Clear validation messages
- Provide context for input errors
- Suggest corrections when possible

### 8. Accessibility
- Support mobile and desktop layouts
- Responsive design
- Intuitive navigation

### 9. Inspection and Transparency
- Every CV bullet must be inspectable
- Show source events
- Display exclusion reasons

## Acceptance Criteria
- Intuitive, low-friction event capture
- Clear metadata management
- Transparent CV generation
- Helpful user feedback
- Consistent experience across devices

## Non-Functional Requirements
- Fast, responsive interface
- Minimal cognitive load
- Support for diverse user backgrounds
- Accessibility compliance
