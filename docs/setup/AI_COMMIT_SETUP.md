# AI Commit Attribution Setup Guide

## Quick Start

This guide will help you set up AI commit attribution for the KaRiya project in under 5 minutes.

---

## Step 1: Install Git Hooks

Run the installation script:

```bash
make install-git-hooks
```

Or manually:

```bash
bash scripts/install-git-hooks.sh
```

This will:
- ✅ Install `prepare-commit-msg` hook (adds AI attribution reminder)
- ✅ Install `commit-msg` hook (validates AI attribution format)
- ✅ Configure commit message template

---

## Step 2: Read the Rules

Quickly skim through the AI attribution guidelines:

```bash
cat docs/rules/AI_COMMIT_ATTRIBUTION.md | less
```

**Key points**:
- ALL AI-generated code MUST include attribution
- Format: `AI-Generated-By: <Assistant> (<Model>)`
- Always include: `Reviewed-By: <Your Name>`

---

## Step 3: Try It Out

### Recommended: Use `make ai-commit` Command

The easiest way to create AI-attributed commits:

```bash
# 1. Stage your changes
git add -p internal/service/career/service.go

# 2. Create AI-attributed commit
make ai-commit MSG="feat(service): add event filtering by date range"
```

**What happens**:
- ✅ Validates commit message format
- ✅ Automatically adds AI attribution
- ✅ Adds your name from git config as reviewer
- ✅ Creates the commit

### Alternative: Manual Commit

1. Make changes (or stage existing changes):
   ```bash
   git add <files>
   ```

2. Start commit:
   ```bash
   git commit
   ```

3. Your editor will open with a template. Fill it in:
   ```
   feat(service): add event filtering by date range

   Implement date range filtering for timeline views.
   Improves performance for large event collections.

   Human review confirmed:
   - All tests pass (66/66 passing)
   - No security issues
   - Follows project conventions

   AI-Generated-By: Avante (Claude 3.5 Sonnet)
   Reviewed-By: John Doe
   Closes #56
   ```

4. Save and close. The hook will validate your attribution.

---

## Step 4: Verify Setup

Check that hooks are working:

```bash
# Check latest commit for AI attribution
make check-ai-attribution

# List all AI-generated commits
make list-ai-commits

# Full audit of AI commits
make audit-ai-commits
```

## Common Workflows

### Human-Written Code (No AI)

When committing code you wrote yourself:

```bash
git add <files>
git commit
```

Write your commit message normally (no AI attribution needed):

```
fix(domain): prevent duplicate tags in event validation

Tag deduplication was not working correctly when tags
had different casing. Now normalize to lowercase before
checking for duplicates.

Fixes #87
```

The hook will ask: "Was this code AI-generated? (y/N):"
- Press **N** (or just Enter) to proceed

---

### AI-Generated Code

When committing code generated by AI (Avante, Claude, Copilot, etc.):

```bash
git add <files>
git commit
```

Write your commit message with attribution:

```
feat(cli): add interactive event capture form

Implement BubbleTea form with real-time validation,
character counter, and date parsing.

Features:
- Text input with 2000 character limit
- Smart date parsing (ISO, relative, special keywords)
- Visual focus indicators
- Inline validation with error display

Human review confirmed:
- All tests pass (14/14 passing)
- No security issues
- Follows project conventions

AI-Generated-By: Avante (Claude 3.5 Sonnet)
Reviewed-By: John Doe
Closes #42
```

The hook will validate the format automatically.

---

### Mixed (AI + Human)

When AI generated code but you made significant modifications:

```
refactor(repo): optimize query builder performance

Refactor query building logic to reduce allocations
and improve performance for large filter sets.

Development process:
- Initial implementation by AI
- Performance profiling by human
- Manual optimization of hot paths
- Added benchmark tests

Benchmark results: 40% faster, 60% fewer allocations

AI-Generated-By: Avante (Claude 3.5 Sonnet)
AI-Modifications: Optimized allocations, added benchmarks
Reviewed-By: Jane Smith
```

## Commit Message Template

The commit template (`.gitmessage`) is already configured. It includes:

```
# <type>(<scope>): <subject>
#
# <body>
#
# 🤖 AI ATTRIBUTION (if AI-generated, uncomment and fill):
# AI-Generated-By: <Assistant Name> (<Model Version>)
# Reviewed-By: <Your Name>
#
# Closes #<issue>
```

Just uncomment the AI attribution lines when needed.

---

## Bypassing Hooks (Emergency Only)

If you need to bypass the hooks (NOT RECOMMENDED):

```bash
git commit --no-verify
```

**Only use this for**:
- Emergency hotfixes
- Non-code commits (docs, config)
- When hooks are genuinely broken

**DO NOT use this to avoid AI attribution!**

## Troubleshooting

### Hook Not Running

```bash
# Check if hooks are installed
ls -la .git/hooks/

# Reinstall hooks
make install-git-hooks
```

### Hook Fails Validation

```bash
# Common issues:
# 1. Wrong format - check for parentheses around model
#    ✅ AI-Generated-By: Avante (Claude 3.5 Sonnet)
#    ❌ AI-Generated-By: Avante Claude 3.5 Sonnet

# 2. Missing Reviewed-By
#    ✅ Reviewed-By: Your Name
#    ❌ (missing)

# 3. Forgot to uncomment in template
#    ✅ AI-Generated-By: ...
#    ❌ # AI-Generated-By: ...
```

### Template Not Showing

```bash
# Configure template manually
git config commit.template .gitmessage

# Verify configuration
git config commit.template
# Should output: .gitmessage
```
