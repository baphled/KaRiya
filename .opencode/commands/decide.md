## Process

1. **Clarify the Problem**
   - What exactly are we deciding?
   - What are the constraints?
   - What does success look like?

2. **Challenge Assumptions**
   - What are we assuming?
   - What evidence supports each assumption?
   - What would prove us wrong?

3. **Generate Options**
   - Option A: [Describe]
   - Option B: [Describe]
   - Option C: Do nothing

4. **Evaluate Trade-offs**
   | Factor | Option A | Option B | Option C |
   |--------|----------|----------|----------|
   | Complexity | | | |
   | Risk | | | |
   | Effort | | | |
   | Maintainability | | | |

5. **Consider Second-Order Effects**
   - What happens after we implement this?
   - What downstream effects will occur?

6. **Apply Inversion**
   - How would we fail with each option?
   - What must we avoid?

7. **Make Recommendation**
   - Recommended option with rationale
   - Key risks to monitor
   - Success criteria

## Output

Provide:
- Clear recommendation
- Reasoning behind it
- Trade-offs accepted
- Risks to monitor
- Next steps
