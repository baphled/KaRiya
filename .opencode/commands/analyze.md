Analyze system impacts for the proposed change.

Load the `systems-thinker` skill for systems analysis.
Load the `architecture` skill for structural understanding.

## Change to Analyze
$ARGUMENTS

## Process

1. **Map the System**
   - What components are involved?
   - How do they connect?
   - What data flows through?

2. **Trace Dependencies**
   - What does this depend on?
   - What depends on this?
   - Indirect dependencies?

3. **Impact Analysis**
   - Primary impacts (direct)
   - Secondary impacts (one step removed)
   - Tertiary impacts (ripple effects)

4. **Identify Feedback Loops**
   - Reinforcing loops (amplify change)?
   - Balancing loops (resist change)?

5. **Find Leverage Points**
   - Where can small changes have big effects?
   - What's the minimum viable change?

6. **Consider Boundaries**
   - What's inside the change scope?
   - What's outside but affected?
   - External systems impacted?

## Output

Provide:
- System map (components and connections)
- Dependency tree
- Impact assessment (primary/secondary/tertiary)
- Risks identified
- Recommendations
