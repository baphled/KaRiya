fix: refresh event detail modal after accepting inferred skills

When a user accepts skills from the skill suggestion modal in BrowseTimeline,
the event detail modal now refreshes to display the newly linked skills.

Changes:
- Add refreshEventDetailModal() method to reload event skills and update the modal
- Update updateSkillSuggestionModal() to call refreshEventDetailModal() alongside
  refreshSkillsModal() when skills are accepted
- Event detail modal now shows updated skill count after skill inference

This ensures the detail view reflects the latest state after skill operations.
